# 产品需求文档（PRD）— 阶段 1

## 1. 产品概述

### 1.1 产品名称

Majdata Download Extension（暂定）

### 1.2 一句话描述

在 Majdata Net 下载谱面时，让用户选择「立即下载」或「加入扩展下载列表」，并在扩展界面中批量勾选后导出链接 TXT。

### 1.3 目标用户

- 需要在 Majdata Net 上浏览大量谱面、希望**先标记后统一下载**的玩家
- 计划将下载任务交给**远端机器**（阶段 2）的用户

### 1.4 非目标（阶段 1 不做）

- 不替代站点打包逻辑（不在扩展内实现 JSZip 打包，除非用户选「立即下载」走原站）
- 不修改 Majdata Net 源码或后端
- 不实现远端下载、不上传用户 Cookie 到第三方
- 不做账号同步 / 云队列

## 2. 用户故事

| ID | 作为 | 我想要 | 以便 |
|----|------|--------|------|
| US-1 | 浏览谱面的用户 | 点击下载时弹出选择 | 决定立刻下还是稍后再下 |
| US-2 | 收藏型用户 | 把谱面加入扩展列表 | 浏览时不被打断 |
| US-3 | 批量下载用户 | 在 Popup 里看到已加入的谱面 | 统一管理 |
| US-4 | 批量下载用户 | 勾选多条并导出 TXT | 交给下载器或阶段 2 脚本 |
| US-5 | 任何用户 | 选择「直接下载」 | 体验与现在完全一致 |
| US-6 | 任何用户 | 删除队列中不需要的项 | 保持列表整洁 |

## 3. 功能需求

### 3.1 下载拦截与确认框（F-1）

**触发：** 用户在 `https://majdata.net/*` 点击站点「下载」按钮（列表图标 / 详情页按钮）。

**行为：**

1. 扩展拦截点击（默认阻止原下载）
2. 展示模态确认框，选项：
   - **直接下载** — 关闭对话框，触发站点原有下载流程（见架构文档 bypass 方案）
   - **加入下载列表** — 解析当前谱面信息写入本地队列，Toast 提示成功
   - **取消** — 关闭对话框，不下载、不入队
3. 可选：**「记住本次选择 N 分钟」** 或 **「默认直接下载 / 默认加入列表」**（设置页，P1 可后置）

**数据解析最低字段：**

- `songId`（必填）
- `title`（必填，清洗富文本）
- `pageUrl`（必填）
- `artist`（可选）
- `assets.track/chart/image/video`（必填前三，video 可空）

### 3.2 下载列表存储（F-2）

- 存储：`chrome.storage.local`
- 去重：同一 `songId` 重复加入 → 更新 `updatedAt`，不重复条目
- 上限：默认 500 条，超出提示用户清理（可配置）
- 持久化：浏览器重启后保留

### 3.3 Popup 管理界面（F-3）

扩展图标 Popup（宽 ~360px，高 ~480px）：

| 区域 | 功能 |
|------|------|
| 顶栏 | 队列计数、全选/反选、设置入口 |
| 列表 | 标题、artist、加入时间；checkbox 多选 |
| 底栏 | 「导出选中」「导出全部」「清空选中」「清空全部」 |

交互细节：

- 单击条目可在新标签打开 `pageUrl`
- 长按/删除按钮移除单条
- 空状态文案 + 引导去 majdata.net 浏览

### 3.4 导出 TXT（F-4）

- 仅导出**用户勾选**的条目（「导出全部」= 全选后导出）
- 格式见 [06-export-format.md](./06-export-format.md)
- 触发浏览器下载 `{majdata-queue-YYYYMMDD-HHmmss}.txt`
- 导出后**不自动**从队列删除（用户手动清理）

### 3.5 设置（F-5，P1）

| 设置项 | 默认 |
|--------|------|
| 启用拦截 | 开 |
| 默认动作 | 每次询问 |
| 队列上限 | 500 |
| 导出格式 | txt（jsonl 可选） |

## 5. 验收标准

| 编号 | 标准 |
|------|------|
| AC-1 | 首页列表卡片点击下载 → 出现确认框，选「直接下载」后站点 Toast 进度与 ZIP 行为与未装扩展一致 |
| AC-2 | 详情页 `/song?id=` 同上 |
| AC-3 | 选「加入列表」后 Popup 可见该条，刷新浏览器仍在 |
| AC-4 | 同一 songId 重复加入不产生 duplicate |
| AC-5 | 勾选 3 条导出 TXT，文件含 3 条完整 asset URL |
| AC-6 | 非 majdata.net 域名不注入脚本 |
| AC-7 | 扩展卸载后 storage 清除（浏览器默认行为） |
